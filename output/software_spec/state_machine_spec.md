# 离散状态机与转移规则规范 (State Machine Spec)

## 一、核心状态流转
`INIT` ➔ `RESEARCH` ➔ `DESIGN` ➔ `PLAN` ➔ `EXECUTE` ➔ `REFINE` ➔ `TEST` ➔ `DELIVERED`

## 二、反常态与多级破壁状态转移 (Step 4 破局推演)
针对【商业化可控核聚变电站的数字化孪生与全自主磁约束自愈控制工程蓝图】，我按你要的三重破壁逻辑链来拆。核心判断先放前面：**这个命题的真正难点不在“数字化孪生”本身，也不在“自愈控制”这个说法，而在于聚变等离子体是一个强非线性、多尺度耦合、传感器严重受限、且故障模式尚未被完全枚举的物理系统——传统数字孪生的“建模-同步-预测-控制”闭环在这里会遇到根本性的认识论瓶颈。**

---

## Layer 1｜表象方案（常规套路）

行业里做这类蓝图，通常的套路是这样：

**1. 数字孪生层**
- 建一个高保真等离子体仿真模型（MHD + 输运 + 加热/电流驱动 + 杂质输运）
- 用实验数据做数据同化，实时更新模型状态
- 构建“虚拟托卡马克”，镜像真实装置的电磁、热、粒子行为

**2. 控制层**
- 用强化学习/模型预测控制（MPC）做磁约束控制
- 对已知不稳定性（新经典撕裂模、边界局域模、破裂）做预测和缓解
- 预设一套“自愈策略库”：检测异常 → 匹配策略 → 执行线圈/加热/杂质注入动作

**3. 工程层**
- 边缘计算 + 云超算混合架构
- 数字线程贯穿设计-建造-运行-维护
- 商业化叙事：降低停机时间、延长部件寿命、提高可用率

**这套方案的本质：把聚变装置当成一个“复杂但可建模、可预测、可控制”的工业系统来处理。**

---

## Layer 2｜局部局限（致命盲区）

这套常规方案在商业化场景下会撞上四堵墙：

**盲区一：数字孪生的“保真度-实时性”不可兼得**
- 等离子体湍流输运的完整模拟需要跨越10^9量级的时空尺度
- 实时控制要求毫秒级甚至微秒级响应
- 你不可能在实时闭环里跑第一性原理模型。降阶模型（ROM）一旦降阶，就丢掉了触发破裂的关键非线性细节
- **结果：孪生体在“平时”很准，在“出事前”恰好不准——而商业化最需要它的时刻就是出事前**

**盲区二：故障模式无法被完全枚举，“自愈”策略库必然有盲区**
- 聚变等离子体的破裂前兆有已知类型，但商业堆运行参数空间远大于现有实验装置
- 你无法为“没见过的故障模式”预设策略
- 强化学习在仿真里训练的策略，迁移到真实装置时面临sim-to-real gap
- **结果：所谓“全自主自愈”，在长尾故障面前会退化为“自信地做错事”**

**盲区三：传感器与执行器的物理瓶颈**
- 等离子体内部状态不可直接测量，依赖磁诊断+汤姆逊散射+ECE等间接反演
- 反演本身有延迟、有噪声、有模型依赖
- 线圈电源、加热系统的响应带宽和寿命有限
- **结果：即使算法知道该做什么，物理执行链路也跟不上“自愈”叙事**

**盲区四：商业化要求的是“可验证的安全性与经济性”，不是“智能”**
- 监管机构不会接受一个黑箱神经网络控制商业核设施
- 投资人要的是可用率、度电成本、停机间隔，不是“自主”这个标签
- 数字孪生的价值必须落到“减少多少次非计划停机、延长多少寿命、降低多少维护成本”上
- **结果：常规蓝图交付的是一套漂亮的技术架构，但无法回答“凭什么是商业可行的”**

**总结：Layer 1 的方案在“已知的已知”里很精致，在“已知的未知”里勉强，在“未知的未知”里失效——而商业化恰恰要求你在后两者中存活。**

---

## Layer 3｜颠覆性反超的最优破局解

破局的核心思路：**放弃“全知全能孪生+全自主控制”的幻想，转向“认知边界感知+可控退化+人机共治+物理约束优先”的架构。**

具体分五个反转：

### 反转一：从“高保真孪生”转向“多模型异构孪生 + 不确定性显式化”

- 不追求单一高保真模型，而是并行运行多个不同假设、不同降阶方式的模型
- 实时输出不是“状态估计值”，而是“状态分布 + 模型分歧度”
- 当模型间分歧度超过阈值，系统自动进入保守模式，而不是继续自信控制
- **本质：把“认识论不确定性”变成一等公民，而不是藏在小数点后面**

### 反转二：从“策略库自愈”转向“物理约束下的在线生成 + 安全包络”

- 不预设策略库，而是用物理约束（MHD稳定性边界、线圈电流限制、热负荷限制）定义安全包络
- 在线优化只在安全包络内搜索动作，包络外一律触发可控退化
- 可控退化不是“失败”，而是设计好的分级响应：降参数运行 → 有序关停 → 保护性破裂缓解
- **本质：不追求“永远自愈”，追求“永远不失控”**

### 反转三：从“全自主控制”转向“人机共治 + 可解释决策链”

- 自主系统负责毫秒级稳定控制和已知故障的快速响应
- 人类操作员负责模式切换、异常确认、长尾决策
- 所有自主决策输出可解释的因果链：基于哪些诊断、哪个模型、什么置信度、为什么选这个动作
- 监管接口内建：每个动作可追溯到物理依据和认证规则
- **本质：商业化核设施的“自主”必须是可审计的自主，不是黑箱自主**

### 反转四：从“数字孪生驱动控制”转向“数字孪生驱动实验设计与维护决策”

- 孪生体的最高价值不在实时控制，而在：
  - 预测部件寿命，优化维护窗口
  - 设计下一轮放电方案，减少试错成本
  - 在停机期间做“虚拟放电”，验证新控制策略
- 实时控制用轻量级物理模型+安全包络就够了
- **本质：把孪生体从“控制系统的一部分”重新定位为“商业运营的核心资产”**

### 反转五：从“技术蓝图”转向“可验证商业闭环”

- 定义可量化指标：非计划停机次数、破裂避免率、部件更换间隔、度电成本下降曲线
- 每个孪生/控制模块都必须挂接到至少一个商业指标
- 分阶段验证：先辅助运行 → 再部分自主 → 最后有限自主
- 监管认证路径前置设计，而不是事后补
- **本质：商业化不是技术架构的附属品，而是架构的设计约束**

---

## 最终蓝图逻辑链

```
Layer 1：高保真孪生 + 强化学习控制 + 策略库自愈
    ↓
Layer 2：实时性/保真度矛盾、长尾故障盲区、执行链路瓶颈、商业验证缺失
    ↓
Layer 3：多模型异构孪生 + 不确定性显式化 + 安全包络内在线优化
         + 可控退化分级响应 + 人机共治可解释决策
         + 孪生驱动运营维护 + 商业指标挂接 + 监管前置
```

**一句话总结：商业化可控核聚变的数字孪生与自愈控制，真正的破局点不是“让机器更聪明”，而是“让系统在认识边界内安全地不聪明”——把不确定性、退化、人机共治和商业验证作为架构的第一性约束，而不是事后补丁。**
