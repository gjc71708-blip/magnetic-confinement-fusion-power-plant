## 01. 顶层哲学：六大时间尺度统一与三大第一性原理

传统的聚变控制体系之所以无法走向商业化，本质在于各模块在时间尺度与系统目标上彼此割裂：
- **微秒级** ($`10^{-6}\text{s}`$)：磁流体不稳定性（MHD）在边界撕扯；
- **毫秒级** ($`10^{-3}\text{s}`$)：破裂前兆（Disruption）在微弱信号中浮现；
- **秒级** ($`10^{0}\text{s}`$)：平衡重建与加热驱动在争夺控制权；
- **分钟级** ($`10^{1}\text{s}`$)：偏滤器瞬态热负荷逼近材料烧蚀极限；
- **小时级** ($`10^{3}\text{s}`$)：电网调峰与电力交易现货价格在剧烈波动；
- **年级** ($`10^{7}\text{s}`$)：第一壁与超导磁体在中子辐照下不可逆衰减。

### 1. 全域统一状态空间方程

成果构建了一个使六个世界使用同一种数学语言的统一状态空间：

$$
\mathcal{X}_{\text{global}} = \mathcal{S}_{\text{plasma}} \times \mathcal{S}_{\text{machine}} \times \mathcal{S}_{\text{twin}} \times \mathcal{S}_{\text{control}} \times \mathcal{S}_{\text{market}} \times \mathcal{S}_{\text{health}}
$$

* **工程意义**：诊断输出的不再是孤立的传感器波形，而是等离子体态空间 $`\mathcal{S}_{\text{plasma}}`$ 上的条件概率分布；控制器输出的不再是生硬脉冲，而是控制态空间 $`\mathcal{S}_{\text{control}}`$ 上的可达集决策轨迹；市场下发的不再是电价，而是市场态空间 $`\mathcal{S}_{\text{market}}`$ 上的边界硬约束。

### 2. 三条不可违背的第一性物理原理
1. **等离子体态是唯一物理真值源**：当孪生体仿真、神经网络预测与市场调度对系统状态产生分歧时，以物理诊断与平衡重建的实测真值为唯一裁决凭证；
2. **孪生体是物理本体的可证伪伴随**：数字化孪生体绝非脱离现实的纯仿真器，其输出必须伴随残差与贝叶斯置信度。预测不可被物理诊断证伪的模型，强制剥夺控制干预权；
3. **自愈控制是约束下的最优干预序列**：全自主控制绝非无约束自由，而是把超导热裕度、第一壁耐受度与电网考核硬约束直接写入目标函数，在多维可行域内求解最优。

### 3. 时空解耦准则
确立 **“快环自治、慢环统计、双向约束、单向不依赖”** 的解耦律：微秒级物理反射环不得等待孪生体推演，毫秒级破裂自愈不得等待电网市场信号；而慢尺度系统必须吸纳快尺度系统的积分统计特征。

## 02. 核心成果一：高保真数字化孪生体体系（Plasma-Plant Digital Twin）

```
┌─────────────────────────────────────────────────────────────┐
│  元孪生体 (Meta-Twin)：监控下层模型漂移、贝叶斯置信度与可证伪性   │
├─────────────────────────────────────────────────────────────┤
│  混合孪生体 (Hybrid-Twin)：第一性物理机理 + 数据驱动贝叶斯融合 │
├─────────────────────────────────────────────────────────────┤
│  数据孪生体 (Data-Twin)：非线性降阶模型 (ROM) 与残差增量学习   │
├─────────────────────────────────────────────────────────────┤
│  物理孪生体 (Physics-Twin)：高保真磁流体/回旋动理学微观求解器   │
└─────────────────────────────────────────────────────────────┘
```

### 1. 核心关键指标与硬红线
- **等离子体平衡重建刷新率**：设计目标 **10 kHz**（门槛 ≥ 1 kHz，< 100 Hz 报警）；
- **磁面重建空间分辨率**：**128×128** 极向网格（门槛 ≥ 64×64）；
- **状态估计延迟**：**< 0.5 ms**（门槛 ≤ 2 ms，> 5 ms 触发降级）；
- **磁通面实测偏差**：**± 5 mm**（门槛 ± 15 mm，± 30 mm 报警）；
- **偏滤器热通量预测误差**：**± 8%**（门槛 ± 15%，± 25% 报警）；
- **模型贝叶斯置信度**：**≥ 0.95**（门槛 ≥ 0.90，< 0.70 拒绝下发控制指令）。

### 2. 三级弹性降级与纳秒级时间同步
- **三级降级链路**：10 kHz 全阶模型 → 1 kHz 降阶代理模型 → 100 Hz 预计算查表外推，三级切换时间 < 2 ms；
- **统一时钟**：全域采用 **PTP IEEE 1588** 纳秒级工控授时，时钟同步误差 < 100 ns。

## 03. 核心成果二：三层嵌套全自主磁约束自愈控制系统

```
                      ┌────────────────────────────────────────┐
                      │  第三层：仲裁层 (10^0 s)               │
                      │  - L0~L5 自主等级动态仲裁              │
                      │  - 安全裕度 vs 经济发电帕累托平衡      │
                      └──────────────────┬─────────────────────┘
                                         │ 模式约束下发
                      ┌──────────────────▼─────────────────────┐
                      │  第二层：策略层 (10^-3 s)              │
                      │  - 破裂预测 (MHD前兆辨识)              │
                      │  - 模型预测控制 (MPC) 与自愈干预序列   │
                      └──────────────────┬─────────────────────┘
                                         │ 实时波形设定
                      ┌──────────────────▼─────────────────────┐
                      │  第一层：反射层 (10^-6 s)              │
                      │  - FPGA 纳秒/微秒级硬实时反馈          │
                      │  - 无模型纯负反馈，垂直位移刚性锁死    │
                      └────────────────────────────────────────┘
```

### 1. 核心控制参数
- **控制回路周期**：**10 μs**（工程门槛 ≤ 50 μs，> 100 μs 失稳）；
- **垂直位移响应**：**< 1 ms**（门槛 ≤ 3 ms，> 5 ms 破裂）；
- **破裂缓解动作**：**< 5 ms** 触发弹丸/气体注入（门槛 ≤ 10 ms，> 20 ms 缓解失效）；
- **AI 确定性推理**：**< 200 μs**，禁止非确定性耗时模型。

### 2. 自愈控制目标函数与硬约束

$$
\pi^* = \arg\min_{\pi} \mathbb{E}\left[\sum_{t} \gamma^t \Big( C_{\text{safety}}(x_t, u_t) + \lambda C_{\text{economic}}(x_t, u_t) \Big)\right]
$$

约束条件：

$$
x_t \in \mathcal{X}_{\text{safe}}, \quad u_t \in \mathcal{U}_{\text{actuator}}, \quad \text{Residual}_t < \epsilon_{\text{twin}}
$$

- **AI 安全投影层 (Safety Projection Layer)**：指令下发前经数学投影层裁剪至导体应力与临界电流物理可行域；
- **独立硬件硬联锁**：响应 < 1 ms 的纯继电器/FPGA 链路，不可被软件旁路。

## 05. 核心成果四：商业化运行、电网耦合与全生命周期经济性

### 1. 核心商业运营指标
- **电站全生命周期可用率**：设计目标 **≥ 90%**（门槛 ≥ 80%）；
- **连续单炮等离子体燃烧时长**：设计目标 **≥ 1000 s**（门槛 ≥ 400 s）；
- **全站平均无故障时间 (MTBF)**：**≥ 2000 h**（连续 80 天满负荷运行）；
- **平均修复时间 (MTTR)**：**≤ 4 h**（门槛 ≤ 8 h）；
- **氚自持增殖比 (TBR)**：**≥ 1.10**（硬约束 ≥ 1.05）。

### 2. 电网级交互与度电成本 (LCOE)
- **净电输出效率**：热-电转换后净并网效率目标 **≥ 35%**；
- **自愈系统自身能耗**：严格限制在电站总发电量的 **< 1%**；
- **电网一次调频调峰响应**：控制在 **< 100 ms**；
- **度电成本目标**：商业首堆控制在 **< 100 美元/MWh**。
