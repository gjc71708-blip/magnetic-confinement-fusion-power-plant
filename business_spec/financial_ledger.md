## 组件一：高保真数字化孪生体（Plasma-Plant Digital Twin）

### 1.1 量化指标

| 指标 | 设计目标 | 工程门槛 | 硬约束 |
|---|---|---|---|
| 等离子体平衡重建刷新率 | 10 kHz | ≥1 kHz | <100 Hz不可用于实时控制 |
| 磁面重建空间分辨率 | 128×128 极向网格 | ≥64×64 | — |
| 状态估计延迟（传感器→孪生输出） | <0.5 ms | ≤2 ms | >5 ms触发降级 |
| 等离子体模型保真度（与实测偏差） | 磁通面位置 ±5 mm | ±15 mm | ±30 mm 报警 |
| 破裂预测提前时间 | 30–50 ms | ≥20 ms | <10 ms 无法完成缓解 |
| 热负荷预测误差（偏滤器） | ±8% | ±15% | ±25% 报警 |
| 氚增殖比TBR在线预测误差 | ±3% | ±5% | ±8% |
| 孪生-实体同步偏差 | <1 ms | ≤5 ms | >20 ms 进入安全模式 |
| 数值求解算力 | 2–5 PFLOPS（FP64混合） | ≥500 TFLOPS | — |
| 模型置信度输出 | 每步贝叶斯后验 | ≥0.9 | <0.7 拒绝下发控制指令 |

### 1.2 性能与容灾阈值

- **降级策略**：10 kHz全阶模型 → 1 kHz降阶模型 → 100 Hz查表+线性外推，三级自动切换，切换时间<2 ms。
- **容灾**：孪生计算节点采用2N+1冗余，单节点失效切换<10 ms；GPU/FPGA求解器看门狗超时50 μs。
- **数据完整性**：诊断数据丢失>30%通道持续100 ms，孪生进入“不可信”状态，控制系统强制切到预置安全波形。
- **电磁脉冲/中子辐照**：孪生硬件置于屏蔽区外，光纤延迟<20 μs；抗辐射等级≥100 krad(Si) 或远程隔离。

### 1.3 一线实操规程

1. **每炮前**：执行孪生-诊断交叉标定，注入5组标准平衡，偏差>10 mm则禁止放电。
2. **放电中**：操作员盯守“孪生置信度”与“预测-实测残差”双屏，残差连续20 ms越界即人工确认降级。
3. **每炮后**：24 h内完成数据回灌，模型在线微调（增量学习），版本号与炮号绑定，保留90天可回溯。
4. **具象落地**：孪生与实时控制共用工控时钟（PTP IEEE 1588，同步误差<100 ns）；所有控制指令带孪生签名与时间戳，未签名指令被FPGA硬拦截。

## 组件二：全自主磁约束自愈控制系统

### 2.1 量化指标

| 指标 | 设计目标 | 工程门槛 | 硬约束 |
|---|---|---|---|
| 控制回路周期 | 10 μs（电流/位置） | ≤50 μs | >100 μs失稳 |
| 磁探针/线圈采样率 | 1 MHz | ≥250 kHz | — |
| 垂直位移控制响应 | <1 ms | ≤3 ms | >5 ms 破裂 |
| 破裂缓解触发→MGI/SPI动作 | <5 ms | ≤10 ms | >20 ms 无效 |
| 自愈决策周期 | 1 ms | ≤5 ms | >10 ms 降级 |
| 故障检测率（已知故障集） | ≥99.9% | ≥99% | — |
| 误报率 | <0.1% | ≤1% | — |
| 自愈成功率（单故障） | ≥99% | ≥95% | — |
| 控制指令端到端延迟 | <100 μs | ≤500 μs | >1 ms 报警 |
| AI控制器确定性推理 | <200 μs | ≤1 ms | 非确定性模型禁用 |

### 2.2 性能与容灾阈值

- **分层控制**：L0 FPGA硬实时（10 μs）→ L1 实时OS（1 ms）→ L2 AI自愈决策（10 ms）→ L3 操作员监督（100 ms）。任一层失效，下层接管。
- **容灾拓扑**：线圈电源N+1冗余；控制器三取二表决（TMR）；通信双环网，断链切换<1 ms。
- **自愈边界**：仅允许在“可恢复包络”内动作（如单线圈失效、单诊断漂移、单电源模块降额）；超出包络（多线圈同时失效、真空破裂、冷却丧失）直接执行受控停堆。
- **硬联锁**：独立于软件的FPGA/继电器链，响应<1 ms，不可被AI旁路；触发条件包括：垂直位移>阈值、辐射剂量率、真空度、冷却流量、氚浓度。
- **AI安全**：所有神经网络输出经“安全投影层”裁剪到物理可行域；训练集与在线数据分布偏移检测（KL散度>0.2）即降级到规则控制。

### 2.3 一线实操规程

1. **每炮前**：自检TMR表决、硬联锁回路、MGI/SPI气压与阀门，任一项不合格禁止放电。
2. **放电中**：AI自愈动作自动记录“决策理由链”，操作员可一键接管（接管时间<200 ms），接管后AI转建议模式。
3. **故障后**：24 h内完成根因分析（RCA），自愈策略更新需经离线仿真10^4次炮验证，通过率≥99.99%才允许上线。
4. **具象落地**：控制机柜置于屏蔽厅外，光纤/差分信号进厅；线圈电源与控制器间采用硬线+光纤双通道；每季度做一次“黑启动”演练：全站断电后，从UPS到等离子体放电准备≤30 min。

## 组件三：商业化运行的数字孪生-自愈一体化平台（O&M与电网接口）

### 3.1 量化指标

| 指标 | 设计目标 | 工程门槛 | 硬约束 |
|---|---|---|---|
| 可用率 | ≥90% | ≥80% | <70% 商业不可行 |
| 连续运行时长 | ≥1000 s | ≥400 s | — |
| 平均无故障时间MTBF | ≥2000 h | ≥1000 h | — |
| 平均修复时间MTTR | ≤4 h | ≤8 h | >24 h 影响经济性 |
| 氚自持TBR | ≥1.1 | ≥1.05 | <1.0 不可持续 |
| 净电效率 | ≥35% | ≥30% | — |
| 电网调峰响应 | <100 ms | ≤500 ms | — |
| 预测性维护提前量 | ≥72 h | ≥24 h | — |
| 数据存储 | 每炮≥10 TB原始+衍生 | ≥1 TB | 保留≥5年 |
| 网络安全 | 满足IEC 62443 SL3 | SL2 | — |

### 3.2 性能与容灾阈值

- **运行模式**：稳态H模 → 先进场景 → 安全停堆 → 遥控处理 → 重启。模式切换时间<10 min（遥控）/<24 h（维护后）。
- **容灾**：厂用电丧失时，UPS+飞轮维持控制系统≥5 min，完成受控停堆；氚系统双包容，泄漏率<10^-9 Pa·m³/s。
- **电网接口**：并网点具备低电压穿越、一次调频、黑启动能力；与电网调度数据交互延迟<50 ms，指令确认<200 ms。
- **经济性阈值**：度电成本目标<100 美元/MWh（首堆），容量因子≥70%；孪生-自愈系统自身能耗<电站输出1%。

### 3.3 一线实操规程

1. **日常**：每班次检查孪生置信度、自愈日志、氚浓度、冷却回路；异常项2 h内上报。
2. **每周**：执行一次全系统数字孪生-实体同步校验，偏差>5%则安排停机标定。
3. **每月**：模拟电网调峰与黑启动，验证响应时间与稳定性。
4. **每季度**：全站黑启动演练+网络安全攻防演练；自愈策略库版本审计。
5. **具象落地**：控制室设“孪生墙”（主屏+冗余屏）、硬联锁盘、应急停堆按钮（硬线）；所有操作双人复核，关键指令需生物识别+口令。数据按“炮号-时间-版本”三元组归档，支持监管与保险审计。

## 关键风险与量化红线

- **破裂**：预测<10 ms 或缓解>20 ms → 必须停机整改。
- **氚泄漏**：>1×10^-6 Bq/m³ 环境浓度 → 立即停堆。
- **控制失效**：AI非确定性输出、孪生置信度<0.7、硬联锁不可用 → 禁止放电。
- **网络安全**：任何未授权指令进入控制网 → 切物理隔离，全站安全模式。
